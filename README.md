# InsurePort

Safe-haven portfolio insurance analyzer. Takes a portfolio of US-listed holdings, diagnoses its crash exposure, proposes insurance sleeves (far out-of-the-money S&P 500 puts, spreads, collars, T-bills, Treasuries, gold, trend, long-volatility ETFs) and tests whether each one actually raises the portfolio's compound growth rate, following the "cost-effective risk mitigation" framework of Mark Spitznagel (Universa Investments, *Safe Haven: Investing for Financial Storms*).

Work in progress. Not investment advice. Not affiliated with Universa Investments, Cboe, or Cambria.
